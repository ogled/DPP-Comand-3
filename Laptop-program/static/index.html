Протокол
Справка по формату

telemetry[] — кадры. match: device_id, type, type_input, packet_number, size, min_size, prefix (значение или список). Первый подошедший кадр декодирует пакет.

fields[]: name, type (u8 i8 u16 i16 u32 i32 u64 i64 f32 f64 bool str hex regex), offset (в данных), length (str/hex), scale, add, unit, decimals, bit, mask, enum {"0":"выкл"}, regex (группа 1), пороги warn_min warn_max crit_min crit_max, bad_values.

commands[]: id, name, description, text ("LED {state}") или bytes ("A5 01 {n}", HEX-байты и параметры), params[] (name label type min max default options), suffix, confirm, danger, alarm.

byte_order: "little"/"big" — глобально, можно переопределить в кадре или команде. Файл применяется сразу после сохранения; можно править и во внешнем редакторе.
